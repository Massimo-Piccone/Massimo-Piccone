Verizon publishes an annual Data Breach Investigations Report (DBIR), using statistics from thousands of incidents that were classified using VERIS. Organizations sent data on thousands of security incidents and data breaches to Verizon, whose researchers analyzed that information to highlight new patterns, steady trends, and interesting tidbits in the evolving cybersecurity threat landscape. Anyone can download a copy of the DBIR for free.

Cisco Security, using its own security research, produces annual security reports that you can download for free. With a new approach to security thought leadership, Cisco has expanded the number of titles in the series to include reports for security professionals with different interests. Calling on the depth and breadth of expertise from threat researchers and innovators in the security industry, the reports include the Data Privacy Benchmark Study, Threat Report, CISO Benchmark Study, and others published throughout each year.
