- ﻿﻿Vocabulary for Event Recording and Incident Sharing (VERIS)
	- ﻿﻿Developed by Verizon
- ﻿﻿Open format available for use by organizations, without licensing fees
- ﻿﻿VERIS Community Database (or VCDB)
	- ﻿﻿Open and free repository of publicly reported security incidents

VERIS:
- ==Usage==: Open format for incident information collection and sharing.
- ==Benefits==: Allows comparison of incidents with others, revealing new information sources.
- ==Metrics==: Standard metrics for comparing customer metrics, incident trends, and security control effectiveness.

VERIS community database:
- ==VCDB==: An open and free repository of publicly reported security incidents.
- ==Data Source==: The initial launch of the VCDB contains data from more than 1200 incidents.
- ==Data Structure==: The VCDB uses four main components (actors, actions, assets, and attributes) to describe an incident.
