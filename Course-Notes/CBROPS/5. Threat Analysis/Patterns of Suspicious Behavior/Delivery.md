- Last step is usually analyzing file behavior.
- Can be originated directly from the anomaly itself, or created / modified within the timeframe of the event.
- Extracted content / related files need to be quickly triaged to determine if they have are malicious.

- File analysis begins with identifying the suspicious files themselves
- Typically an executable as its own process on the system, or a library that is loaded into a process that is already running.
- Behavior varies based on the type of malware.
- Identify any related files, as they can affect the malware’s execution.

- ==Malware Execution Mechanism==: Some malware executes another executable as a child process, while others act as “droppers” to download and execute additional files.
- ==Malware Data Exfiltration==: Malware can transfer stolen data, such as credentials or banking information, to a suspicious site or server.
- ==Malware File Behavior==: Malware files can be temporary or persist on disk, potentially in temporary directories.

- ==File Behavioral Analysis==: Analyzing the behavior of files in a controlled environment to determine their nature.
- ==Sandbox Functionality==: Executes files in a safe, isolated environment for monitoring and analysis.
- ==Malwr.com as a Sandbox==: A platform for uploading files for automated analysis and potential signing based on their behavior.

- ==Malware Detection Method==: Uses hashes to compare submitted samples with known malware.
- ==Sandbox Analysis==: Runs samples through a sandbox for analysis if no match is found.
- ==Report Content==: Provides a comprehensive report with detailed results.

![7](/Course-Notes/.assets/Pasted_image_20241125180551.png)
![6](/Course-Notes/.assets/Pasted_image_20241125180555.png)

- ==Malware Information==: Filename, size, hash, and antivirus signatures.
- ==Antivirus Analysis==: Analysts can reference antivirus signatures for vendor analysis.
- ==Future Identification==: Unique identification of malware samples.

- ==Malware Behavior Report==: Documents popups generated by the malware and IP addresses/domains it attempts to contact.
- ==Anomaly Detection==: Cross-reference the report with previous PCAP analysis for anomaly detection.
- ==Investigation Clues==: Provides information on files, registry keys, and mutexes associated with the malware sample.

Look for Answers:
- Where did the malware come from?
- What was the method and point of entry?
- Where has it been and what systems were affected?
- What did the threat do and what is it doing now?
- How is the threat stopped and root cause eliminated?
