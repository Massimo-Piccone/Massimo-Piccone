- ==Zero Trust Definition==: A comprehensive approach to securing all access across networks, applications, and environments.
- ==Zero Trust Goal==: Reduce risks to the network and make security easy and accessible for everyone.
- ==Zero Trust Implementation==: Verify the identity of all users and devices attempting to access a protected application before granting access.

Zero trust model protects the following:
- Workforce
- Workload
- Workplace

## Zero Trust Workforce Protections

- ==Zero Trust Workforce Definition==: Ensures only authorized users can access required work applications from any location.
- ==Authorized Users==: Employees, contractors, partners, and vendors.
- ==Access Control==: Users access work applications using secured personal or corporate-managed devices.

![3](/Course-Notes/.assets/Pasted_image_20241121141620.png)

- ==Security Risks in User Accounts==: Unavoidable risks exist in every user account, including inactive accounts used by former employees.
- ==Zero Trust for Workforce Security==: Implementing zero trust principles, such as multifactor authentication, is crucial for securing the workforce.
- ==Multifactor Authentication Benefits==: Strengthens access security by requiring two verification methods, enhancing user identity assurance.

## Zero Trust Workload Protections

- ==Zero Trust for Workload Definition==: Ensures secure access for APIs, microservices, and containers accessing applications in cloud, data centers, and virtualized environments.
- ==Zero Trust for Workload Goal==: Secure access when workloads interact with each other.

![2](/Course-Notes/.assets/Pasted_image_20241121141702.png)

- ==Data Center Infrastructure==: Hybrid multicloud infrastructure using bare-metal, virtualized, and container-based workloads.
- ==Workload Definition==: Compute stack, associated application, and requests made to the application, running in various environments.
- ==Cloud Workload Prediction==: Cisco estimates 94% of workloads will run in cloud environments by 2021, with 6% processed by traditional data centers.

This dynamic environment has created several challenges that organizations must address:
- ==Insufficiency== of static perimeter-based security model in a data center to cope with current technology.
- ==Lack of ability== to generate and manage policies for segmentation based on application behavior.
- ==No consistent approach== to implementing segmentation using allowed list across a multicloud infrastructure.
- ==Lack of a comprehensive approach== to reduce the attack surface, minimize lateral movement, and detect behavior deviations.

- ==Platform Functionality==: Cisco Tetration platform uses traffic telemetry data to provide comprehensive workload protection for a multicloud data center.
- ==Platform Features==: Cisco Tetration secures hybrid, multicloud workloads and contain lateral movement with application segmentation, and provides complete visibility and determine the dependencies within databases and applications.
- ==Platform Purpose==: Cisco Tetration platform is designed to address challenges in multicloud data centers.

## Zero Trust Workplace Protections

- ==Zero Trust Definition==: Ensures secure access for any devices connecting to enterprise networks.
- ==Zero Trust Scope==: Applies to all devices, including IoT devices, user endpoints, servers, printers, cameras, HVAC systems, kiosks, infusion pumps, and industrial control systems.

![1](/Course-Notes/.assets/Pasted_image_20241121141901.png)

- ==Zero Trust Model Goal==: Secure all user and device connections across the network, including IoT.
- ==Zero Trust Model Mechanism==: Grant access only to authorized users, devices, and workloads after establishing trust and preventing threats.
- ==Cisco SD-Access Functionality==: Provide insight into users and devices, identify threats, and maintain control over all network connections, including IoT devices.

## Zero Trust Model Security Vision

- ==Zero Trust Model Definition==: A security vision integrating various security solutions to secure the workplace, workload, and workforce.
- ==Zero Trust Model Benefits==: Provides better visibility, reduces attack surface, and offers a consistent and productive security experience for users.
- ==Zero Trust Model Mechanism==: Requires verification of security states for every access request, segments resources, and limits permissions and traffic.
