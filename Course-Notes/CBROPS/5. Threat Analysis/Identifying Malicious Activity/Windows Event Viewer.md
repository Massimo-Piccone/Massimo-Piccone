- Purpose of Windows Event Viewer: Enables browsing and managing event logs for system monitoring and troubleshooting.
- Functionality: Microsoft management console snap-in.

![1](/Course-Notes/.assets/Pasted_image_20241122101500.png)

1. Use Event Viewer to troubleshoot a problem.
2. Locate events related to the problem.
3. Filter for specific events across multiple logs.
4. Display all potentially related events.

- Windows Application Logs
- Windows Services Logs

To start Event Viewer using the Windows interface:

1. Click the **Start** button
2. Click **Control Panel**
3. Click **Administrative Tools**
4. Double-click **Event Viewer**

- Event Viewer Launch: Open a Windows command prompt and enter the eventvwr command.
- Event Logging Example: A Windows user’s successful login attempt is logged as an Audit Success Login event.
