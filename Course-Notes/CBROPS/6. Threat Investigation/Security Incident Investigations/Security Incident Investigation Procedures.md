# [[Quick Reference]]

Key Questions in Security Incident Investigation

| Question | Description                                                         |
| -------- | ------------------------------------------------------------------- |
| Who      | Identifies the IP/domain associated with the malware.               |
| What     | Determines the type of malware present on the system.               |
| When     | Establishes the time the event occurred, typically recorded in UTC. |
| Where    | Identifies the geolocation of the originating source of the attack. |
| Why      | Explores the intended purpose of the malware.                       |
| How      | Investigates how the malware infiltrated the system.                |

Key Tools

- **VirusTotal**: A website that analyzes files and URLs for viruses, worms, trojans, and other kinds of malicious content.
- **Tracert**: A command-line tool used to trace the path that a packet takes to reach a destination, useful for identifying the route of network traffic.
- **Malwr.com**: A sandbox environment for analyzing malware behavior and capabilities.

Key Concepts in Malware Investigation

- **Initial Alert**: The first indication of a potential security incident, often generated by an IDS or IPS.
- **Attribution**: The process of identifying the source of an attack, which can be complicated by the use of compromised devices.
- **Infection Vector**: The method by which malware gains access to a system, often through email attachments or malicious websites.

Key Malware Examples

- **Stuxnet**: A sophisticated worm designed to target industrial control systems, specifically in nuclear facilities, with the intent to disrupt uranium enrichment.
- **Coreflood**: A type of botnet malware that communicates with an IRC server to receive commands and perform malicious activities.

Facts to Memorize

- Common malware types: Virus, Worm, Trojan, Ransomware, Spyware, Adware.
- Key geolocation tools: VirusTotal, WhatsMyIP.com, IPCIM.com, checkIP.org, IP Location Finder, IP2Location.
- Standard time reference: UTC (Coordinated Universal Time).
- Importance of not relying solely on IDS/IPS alerts for threat detection.

Reference Information

- Regional Internet Registries (ARIN, RIPE, APNIC, AfrNIC, LACNIC) manage IP address distribution.
- Accuracy rates for geolocation services vary: 50%-80% for city accuracy, 95%-99% for nation-state determination.
- VirusTotal provides a community investigation of malware with detection ratios from various antivirus engines.

Cause and Effect

|Cause|Effect|
|---|---|
|Malware infection via email attachments|User executes malicious file, leading to system compromise.|
|Use of insecure coding practices by developers|Increased vulnerability to remote code execution (RCE) exploits.|
|Delivery of malware through deceptive websites|Users download malicious files believing they are legitimate security software.|
|Geolocation analysis of IP addresses|Helps identify potential threat sources and assess the legitimacy of alerts.|

Problem-Solving Steps

1. **Identify the alert**: Review the IDS/IPS alert to gather initial information.
2. **Determine 'Who'**: Analyze the source IP/domain associated with the alert.
3. **Determine 'What'**: Identify the type of malware involved, if possible.
4. **Determine 'When'**: Check the timestamp of the alert to understand the timing of the event.
5. **Determine 'Where'**: Use geolocation tools to find the physical location of the source IP.
6. **Determine 'Why'**: Investigate the purpose of the malware and its intended impact.
7. **Determine 'How'**: Analyze the infection vector to understand how the malware entered the system.

**Tips**: Always escalate complex alerts to senior analysts for deeper investigation.

# Objectives of Security Incident Investigation

### Key Questions in Investigations

> The primary goal of a security incident investigation is to answer critical questions regarding the incident.

- **Who**: Identify the IP/domain associated with the malware.
- **What**: Determine the type of malware present on the system.
- **When**: Establish the timeline of the event.
- **Where**: Ascertain the geolocation of the attack's origin.
- **Why**: Understand the purpose behind the malware's design.
- **How**: Investigate the method of malware entry into the system.

### Triggers for Investigation

> Investigations can be initiated by various unpredictable events, often starting with alerts from IDS or IPS systems.

- Alerts can vary in sophistication, leading to one, many, or no alerts at all.
- Relying solely on IDS/IPS alerts can be misleading, especially against advanced threats.
- Vigilant users can also play a role in identifying suspicious activities, similar to IDS/IPS systems.

### Understanding the Alert

> Analyzing an IDS alert can help answer the who, what, when, where, why, and how of an incident.

- The alert's timestamp is crucial for determining when the event occurred, recorded in UTC/GMT for consistency.
- Example: An alert from Snort IDS can provide insights into the nature of the attack.

### Attribution Challenges

> Identifying the source of an attack is one of the most complex challenges in cybersecurity.

- Example: An access attempt via SMB IPC$ share can obscure the true identity of the attacker.
- Analysts must avoid premature conclusions about the attacker's identity, as they may be using compromised devices to mask their location.

# Geolocation of Threat Actors

### Determining the Source Location

> Understanding the geographical origin of an attack can help in assessing the threat level.

- Analysts should not only identify the source device but also the physical location of the threat actor.
- Certain regions are known for hosting malicious activities, which can inform the investigation.

### Tools for Geolocation

> Various tools can assist in determining the geolocation of an IP address, including:

- **VirusTotal**
- **WhatsMyIP.com**
- **IPCIM.com**
- **checkIP.org**
- **IP Location Finder**
- **IP2Location**
Caution: The accuracy of these tools can vary, and the data is only as reliable as the sources used.

# Geolocation Services and IP Address Tracking

### Overview of Geolocation Services

- Geolocation services utilize databases to track IP address data, providing location information based on IP addresses.
- The primary source of IP address data is the Regional Internet Registries (RIRs), which manage and distribute IP addresses globally.
- RIRs are crucial for maintaining the integrity and accuracy of IP address allocation in different regions.

### Example of IP Address Lookup

- An example IP address, 72.163.4.161, is provided by a user to a geolocation service.
- The service retrieves information associated with the IP, such as the organization (e.g., Cisco Systems) and the domain (e.g., www1.cisco.com).
- The geolocation data reveals the country (United States), state (Texas), city (Frisco), and approximate latitude and longitude.

# Malware Identification and Analysis

### Types of Malware and Investigation Protocols

- Identifying the type of malware is critical during a threat investigation; Tier 1 SOC analysts should escalate alerts when unsure.
- Alerts triggered by specific malware detection rules (e.g., Snort) can streamline the investigation process.
- Analysts should submit malware samples to VirusTotal for cross-referencing against various antivirus definitions.

### VirusTotal and Its Role in Malware Analysis

- VirusTotal, acquired by Google in 2012, is a vital tool for analysts to assess the maliciousness of files.
- The platform provides a community investigation feature, allowing users to see detection ratios from multiple antivirus engines.
- Example: The NotPetya malware sample shows a high detection rate, indicating its widespread recognition among antivirus solutions.

### Understanding Malware Functionality and Intent

- Analysts should explore the 'why' behind malware development, focusing on its functionality and purpose.
- The Stuxnet malware serves as a case study, targeting industrial control systems to disrupt uranium enrichment processes.
- Understanding the intent behind malware can inform analysts about potential impacts and necessary responses.

# Malware Infection Vectors

### Common Infection Vectors

- Malware often enters systems through malicious email attachments or links that users inadvertently execute.
- Cleverly crafted websites can trick users into downloading malicious files, often disguised as security software.
- Web browsers like Google Chrome provide warnings against suspicious sites, but users may ignore these alerts.

### Analyzing Infection Methods

- Analysts can verify the presence of alerts on host systems to trace the delivery method of malware.
- Full packet captures and tools like ELSA can help identify previous communications with suspicious IP addresses.
- Understanding the delivery mechanism is crucial for preventing future infections and enhancing security measures.
