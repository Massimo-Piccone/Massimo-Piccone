# **Phishing traffic**

- There are a lot of phishing emails with links to fake login sites. 
- Almost all of these are HTTPS links. 
- Lots of **ipfs.io** links, and IPFS is a peer-to-peer distributed file system, which makes the fake login pages even harder to take down.

# Linux malware (IRC C2 for hacker botnet)

`http.request or irc.request.command contains NICK`

![2](/Wireshark/.assets/Screenshot_2025-03-10_at_10.11.45.png)

- Retrieves ELF files from **ddoser.org**.
- Connects/attempts to connect to several different IRC channels, most over TCP port 6667.
- Some of the IRC channels are on non-standard ports for IRC, like TCP port 20 or TCP port 53.
- Only one IRC channel stays connected for any length of time: **tcp.stream eq 12**
