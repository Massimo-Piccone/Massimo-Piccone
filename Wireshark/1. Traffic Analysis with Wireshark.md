# Basics
## 1. Identifying Hosts and Users 

### `Host Information`

Identifying hosts and users within a network is a fundamental aspect of cybersecurity. Understanding the characteristics of devices connected to the network is crucial for maintaining security and monitoring potential vulnerabilities.
#### `MAC Address`

A Media Access Control (MAC) address is a unique identifier assigned to a device for local network communication. The first three bytes of a MAC address are used to represent the vendor ID, such as Apple, Dell, Cisco, etc.

>Important Note: 
>While the MAC address can provide insight into the device's manufacturer, it is important to note that a MAC can be mainulated or spoofed on many devices. Therefore, the vendor ID may not always accurately reflect the actual vendor of the device.

![10](/Wireshark/.assets/Screenshot_2025-03-10_at_01.16.56.png)
#### `IP Address`

An Internet Protocol (IP) address is another key identifier for devices on a network. It serves two main functions: identifying the host and providing the location of the device within the network.
#### `Host Name`

The host name is a human-readable label assigned to a device connected to a network. It is used to identify the device in various network-related contexts.

##### `DHCP Packets`

DHCP packets are essential for managing IP address allocation within a network. When a device joins a network, it requests an IP address from a DHCP server, which responds with the necessary configuration information, including the device's IP address.

![9](/Wireshark/.assets/Screenshot_2025-03-10_at_01.26.44.png)

##### `NBNS Packets`

NetBIOS Name Service (NBNS) packets are used for name resolution in Windows-based networks. They help devices locate each other by translating host names to IP addresses, enabling seamless communication within local networks.

## 2. Identifying OS and web browser

Web browsers can be identified through the `User-Agent` string present in HTTP requests. This string often contains the browser version, OS, and sometimes even the device type.

**- Finding User-Agent in Wireshark:**
    - Use the display filter `http.request` to show only HTTP requests.
    - Follow TCP Stream or locate the `User-Agent` field in the request headers.

![7](/Wireshark/.assets/Screenshot_2025-03-10_at_01.38.34.png)
![6](/Wireshark/.assets/Screenshot_2025-03-10_at_01.42.46.png)

- `Mozilla/5.0:` Legacy identifier that is included for compatibility reasons.
- `Windows NT 10.0`: Operating System is `Windows 10` or newer.
	- `Win64; x64`: Architecture of the processor.
- `AppleWebKit/537.36`: The `rendering engine` and its version.
- `(KHTML, like Gecko):` Legacy compatibility statement.
- `Chrome/110.0.0.0:` Identifies the actual web browser and version
- `Safari/537.36:` Claims to be compatible with `Safari`.
- `Edg/110.0.1587.69:` This clarifies that the browser is actually `Microsoft Edge`, not Chrome.
	- This is to avoid confusion with Google Chrome, since Edge is also built on Chromium).

## 3. Identifying users in an AD environment

#### `kerberos.CNameString`

**Kerberos** is an authentication protocol commonly used in Active Directory environments to securely authenticate users and services. The `CNameString` in Kerberos refers to the **client name** or the **principal name** of the user requesting access to a service.

When a user tries to access a resource, Kerberos will be used to authenticate the user. During this process, a **ticket** is generated that contains the **client name** (`CNameString`), which is typically in the format of a **user’s username** or **domain\user**.

- This field identifies the **username** (the client) involved in the authentication process.

![5](/Wireshark/.assets/Screenshot_2025-03-10_at_01.53.57.png)

You might find a first and last name from the user account in traffic for Lightweight Directory Access Protocol (LDAP).

#### `ldap contains "CN=Users"`

LDAP is a protocol designed to query, manage, and interact with directory services like AD. Since Active Directory stores **user accounts** in the directory, **LDAP queries are frequently used to retrieve or manipulate user-related information**.

When an administrator or service needs to authenticate or get details about a user, they typically query the `CN=Users` container. Identifying these LDAP queries helps to understand which users are being accessed or manipulated within the AD environment, aiding in troubleshooting and security monitoring.

- You can filter packets using this string to find LDAP queries that involve user accounts.

![4](/Wireshark/.assets/Screenshot_2025-03-10_at_02.01.48.png)

#### `SMB`

SMB is used by clients to connect to file shares, printers, and other resources. SMB transactions often include **username**and **domain** information for access control. By capturing SMB packets, especially those involved in authentication (such as **NTLMSSP** or **Kerberos** authentication), you can gather details about which users are trying to access resources.

![3](/Wireshark/.assets/Screenshot_2025-03-10_at_02.08.13_1.png)

#### `ip contains "DESKTOP-"`

IP packets themselves don't directly contain the hostname of a device. However, hostnames can appear in IP packets through the use of higher-level protocols such as **DNS**, **HTTP**, **SMB**, **NetBIOS**, **mDNS**, and **DHCP**, which sometimes embed hostname information.

 `"DESKTOP-"` is a frequently used as a prefix for machine names in Windows environments. This search will help identify traffic related to Windows-based devices that are named using the `"DESKTOP-"` naming convention. This can be useful for pinpointing where specific user activity is taking place or identifying user machines in the environment.
