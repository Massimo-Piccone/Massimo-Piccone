### Swarm Protocol

**Windows Update Delivery Optimization (WUDO)**
- Devices on the same LAN (or even across the internet, depending on settings.)
- Devices retrieve parts of the update from other Windows PCs that have already downloaded the update.
- WUDO is **enabled by default** on Windows devices.

**TCP Port 7680**: This port is used by **Windows Update Delivery Optimization (WUDO)**. Introduced in Windows 10, It enables devices to download Windows updates from other devices on the same local network (LAN) or even from the internet. This peer-to-peer feature helps reduce the load on Microsoft’s update servers and optimizes the update process.

- **Implications for Network Traffic Analysis**:
    - LAN network traffic over TCP port **7680** might appear regularly for update purposes. This is **non-malicious traffic** and is expected behavior for Windows devices.
    - Recognizing known traffic patterns like WUDO can help prevent misidentification of legitimate activity as malicious.

## **DNS over HTTPS** 
> AKA Secure DNS / DoH

DoH queries are encapsulated within HTTPS requests, meaning they are practically indistinguishable from regular web traffic, making it difficult for third parties to monitor or manipulate DNS requests. DNS over HTTPS (DoH) offers privacy, security, and flexibility benefits by encrypting DNS queries, preventing tracking, and bypassing censorship. 

![32](/Wireshark/.assets/Screenshot_2025-03-16_at_11.17.31.png)

DoH is Enabled by default on Chrome and Edge using your current Internet service provider.

## **QUIC and Chrome-based browser traffic**

Quick UDP Internet Connections is a Google-developed protocol offering improved performance, latency and security. QUIC was designed to make TCP traffic obsolete for many applications. UDP port 443. 

 **.goog** is a top-level domain controlled by Google, while **gvt1.com** and **gvt2.com** are used primarily for delivering **Chrome** and **Edge** updates securely and efficiently. These domains are integral to Google's infrastructure, providing quick updates for browsers that use the latest security patches and features.

# File transfers over SMB

![4](/Wireshark/.assets/Screenshot_2025-03-10_at_04.43.26.png)![3](/Wireshark/.assets/Screenshot_2025-03-10_at_04.44.21.png)![2](/Wireshark/.assets/Screenshot_2025-03-10_at_04.44.48.png)

Export **pcap-analysis.notes.txt**

Whenever you export SMB objects, ensure the entry shows [100.00%] before you export it.

```
17060 \\PCAPWORKSHOP-CD\SharedFiles
FILE(59/59) \[100.00%] 59 bytes \pcap-analysis-notes.txt
```

Review the TCP stream for the SMB traffic to see how it’s transferred.

`smb2.filename eq "pcap-analysis-notes.txt"`
